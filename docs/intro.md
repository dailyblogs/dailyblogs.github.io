# Daily Blogs Docs

Daily Blogs is a public cloud engineering knowledge base focused on production-grade platform design, DevSecOps, Site Reliability Engineering, Kubernetes, Terraform and cloud architecture.

The content is written as generic, sanitized engineering guidance. It avoids client names, employer names, internal project details, sensitive identifiers, internal URLs, account IDs, IP addresses, and private implementation details.

## Learning tracks

- Azure / AKS
- AWS Platform
- Terraform / IaC
- DevSecOps
- SRE / Observability
- Interview Preparation
